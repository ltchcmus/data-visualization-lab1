# 📊 Data Visualization - PlotTwist

## 1. Giới thiệu

**PlotTwist** là một dashboard trực quan hóa dữ liệu sách trên nền tảng Tiki, được xây dựng bằng **Streamlit** và **Plotly**. Ứng dụng giúp phân tích, khám phá và trình bày dữ liệu một cách trực quan, dễ hiểu.

---

## 2. Yêu cầu môi trường

- Hệ điều hành: Windows / Linux / macOS
- Python: >= 3.10
- Pip

---

## 3. Cách chạy nhanh

### Bước 1: Tạo môi trường ảo

```powershell
python -m venv .venv
```

### Bước 2: Kích hoạt môi trường ảo

```powershell
.\.venv\Scripts\Activate.ps1
```

### Bước 3: Cài đặt thư viện

```bash
pip install -r requirements.txt
```

### Bước 4: Chạy dashboard

```bash
streamlit run src/dashboard/app.py
```

-> Sau khi chạy, mở trình duyệt theo địa chỉ được hiển thị (thường là: http://localhost:8501)
